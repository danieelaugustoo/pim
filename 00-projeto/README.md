# 00-projeto

**O que guarda:** os arquivos de controle do PIM: regras do manual, glossário, rastreabilidade (exigência → arquivo → capítulo → status), cronograma das sprints e lista de integrantes com papéis no Scrum.

**Exigências do manual que atende:** não corresponde a uma etapa específica. Dá suporte às regras gerais (seção 2 do `PLANO.md`: autoria, grupo, formatação e entrega) e permite conferir, no fim, se cada exigência das etapas 1 a 8 e do documento final foi cumprida.
